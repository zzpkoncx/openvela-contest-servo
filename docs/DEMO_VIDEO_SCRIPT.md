## 详细脚本

### L01 开场（0:00-0:20）

**[画面：屏幕录制，桌面 + 板子连接电脑]**

> "嗨大家好，我是 393 队的 [你的名字]。今天给大家看一个用 openvela 做的小玩意儿——桌面小跟班。
> 你有没有过这种体验：一个人对着电脑加班，想找个人说说话，但又不想掏手机？
> 我们的解决方案是——一个会听、会看、会动的桌面机器人。"

### L02 自我介绍（0:20-0:50）

**[画面：板子特写 + 真人出镜]**

> "这是我们的硬件——LilyGO T-Display-S3，ESP32-S3 加一块 1.9 寸的 ST7789 屏幕，
> 上面接了一个 270 度的舵机，还有 INMP441 麦克风。
> 软件用的是小米开源的 openvela，一个基于 NuttX 的物联网操作系统。
> 我们的项目就一个核心理念：让 AI 真的'活'在桌面上。"

### L03 演示 1：基础对话（0:50-1:40）

**[画面：板子正面 + 串口日志（左右分屏）]**

> "来，我们直接开始测一下。
> （对着板子）'你好，openvela'——"

**[板子：表情变思考、播提示音]**

> "它听到了。现在说：'把表情换成开心'——"

**[板子：表情变开心 + 舵机点头]**

> "我让它笑一个，它就笑了。再来：'舵机转到 90 度'——"

**[板子：舵机转到 90°]**

> "再让它摇个头：'让舵机摇个头'——"

**[板子：舵机来回摆头]**

> "你看，所有控制都通过语音完成，没有按键、没有触屏。"

### L04 演示 2：舵机 + 表情（1:40-2:30）

**[画面：板子慢动作特写]**

> "重点说一下这个舵机和表情的联动。
> 比如我让它'生气'——"

**[板子：表情愤怒 + 舵机快速左右摆]**

> "你看，表情愤怒的时候，舵机也跟着'摇头'，像是在表达不满。
> 再来'比个心'——"

**[板子：表情爱心眼 + 舵机慢点头]**

> "它就温柔地点头示爱。"

### L05 演示 3：主动简报（2:30-3:10）

**[画面：分屏——左侧板子，右侧手机时间显示 07:00]**

> "最让我骄傲的功能是——**主动**简报。
> 每天早上 7 点，它会自动播报：'早上好，今天是 X 月 X 日，农历 X，天气 X 度 X'，
> 还会贴心地提醒我今天有什么日程。
> （播一段录好的早安简报音频）"

**[画面：板子表情从睡觉 → 思考 → 开心，舵机点头]**

> "你看，'主动'不是说它会蹦出一句话，而是会**执行**一系列动作：
> 表情切换 + 舵机动作 + TTS 播报 + 表情回正。"

### L06 技术架构（3:10-3:50）

**[画面：屏幕录制架构图]**

> "技术上，我们没有重造轮子。openvela 自带的 ai_agent 框架已经实现了：
> 火山引擎 ASR + 豆包 LLM + 火山 TTS 的完整链路。
> 我们做的事，**只有两件**——"

**[画面：标红这两块]**

> "第一：写 4 个 Skill，描述我们板子能干什么（表情、舵机、天气、简报）。
> 第二：写一个叫 desktop_pet 的 C 应用，监听 Skill 调用、执行硬件动作。
> 这样既满足大赛'必须用 openvela 系统能力'的硬指标，又把工作量压到最小。"

**[画面：4 个 Skill 文件目录特写]**

> "Skill 本质上就是 4 个 Markdown 文件。LLM 自动读它们、决定什么时候调用。
> 这就是现代 AI Agent 的范式。"

### L07 创新点（3:50-4:30）

**[画面：文字动画列出 3 个点]**

> "我们的创新点有 3 个：
>
> 第一，**表情 + 动作 + 语音三位一体**。
> 别的桌面机器人要么只能动嘴，要么只能动脸。我们同步三个通道，体验更自然。
>
> 第二，**完全离线可选**。基础对话走云端，但 LLM 返回后所有动作都在本地。
> 哪怕断网，表情和舵机照样工作。
>
> 第三，**生态友好**。我们贡献的 4 个 Skill 都是 Markdown，理论上任何 openvela 板子都能用。"

### L08 致谢（4:30-4:50）

**[画面：真人 + 板子]**

> "感谢 openvela 团队提供了这么好用的框架。
> 感谢小米和赛事方举办这个比赛。
> 我们是 393 队——极速派，欢迎大家围观我们的仓库。
> 链接在屏幕上，GitHub 搜 contest2026_393_jizhipai 就能找到。"

**[画面：屏幕显示 GitHub 链接]**

> "最后让小跟班跟大家说再见——'再见'"

## 备用方案

如果真机演示出问题：
- 用模拟器录屏（`./emulator.sh`）— 至少能展示逻辑
- 用 esp32s3-eye 母本（不移植 T-Display-S3）— 节省板级适配时间
- 用之前 MicroPython 版的视频片段兜底
